# mofikoo.github.io

Redirects only. `Quizz/` forwards the old GitHub Pages address of the Anatomy app
(mofikoo.github.io/Quizz) to https://studyanatomy.vercel.app, carrying the progress saved
in the browser along. `valoracion-cards/` forwards the old clinical tests site to
https://studyanatomy.vercel.app/tests. Both original repositories are private, so they no
longer have Pages sites of their own.
